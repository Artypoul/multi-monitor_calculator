# OpenCode Skills — multi-monitor_calculator

Набор skills для текущего SvelteKit/SMUI репозитория.

## Основные сценарии

- `feature` — полный цикл от задачи до PR.
- `frontend-plan` — план до кода.
- `data-load-review` — ревью data flow, local endpoints и server-side bridge.
- `affordance-review` — UI affordance и form-save scope.
- `flow-debug-checklist` — проверка многошагового пользовательского сценария.
- `frontend-safety-check` — финальный frontend safety pass перед PR.
- `pr-finalize` — checks, docs и PR в `master`.

## Важное

- Harness перенесён из `vps_artpol`; встречающиеся в skill-примерах auth/onboarding-cases — это примеры проверки flow-рисков, не literal contract текущего продукта.
- Канонические правила проекта: `AGENTS.md` и `CLAUDE.md`.
