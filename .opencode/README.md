# OpenCode harness — multi-monitor_calculator

Этот каталог содержит OpenCode-версию agent harness, перенесённую из `vps_artpol` и адаптированную под текущий репозиторий.

## Что важно помнить

- Канонические правила проекта лежат в `AGENTS.md` и `CLAUDE.md`.
- Default agent сохранён под именем `gigma-frontend` ради совместимости, но он теперь обслуживает весь frontend этого репозитория.
- Base branch: `master`.
- Вместо `history.md` здесь обычно обновляются `docs/` и `README.md`.

2. Реализовать
