# Калькулятор ремонта

SvelteKit MVP для предварительного расчета ремонта санузла через готовый headless-расчет.

## Frontend user flow

На главной странице работает клиентский мини-эп для предварительной сметы:

- короткая форма объекта без обязательных контактов;
- параметры квартиры и санузла;
- предварительная смета для пакета "Санузел под плитку";
- список основных работ и материалов;
- контактная форма после результата;
- дополнительные детали по площадям, графику и материалам.

CTA "Оставить заявку" показывается после предварительной сметы, готовит карточку заявки на экране и проверяет имя/телефон. Реальная отправка заявки в ERP подключается отдельно, когда известен backend-контракт для создания заявки.

Формулы, шаблоны квартир, категории и frontend-представления лежат в `src/lib/repairFlow.ts`.
Backend, server endpoints, token handling и technical mapping для расчета лежат в `src/lib/server/*` и `src/routes/api/repair-estimate/calculate`.

## Env

Создайте `.env` локально и добавьте:

```bash
GIGMA_APP_TOKEN=...
```

Опционально можно переопределить базовый URL:

```bash
GIGMA_API_URL=https://api.gigma.ru/api
```

`GIGMA_APP_TOKEN` читается только server-side кодом. Браузер отправляет запрос только в локальный route `POST /api/repair-estimate/calculate`.

## Mapping

Mapping сценария `bathroom_tile` лежит в `src/lib/server/repairEstimateMapping.ts`.

MVP отправляет в Gigma работы:

- 34777 Наливной пол, толщина 5
